# mysait

IMPORTANT: All website content, text, buttons, menu items 
must be in POLISH LANGUAGE. This is a Polish fast food 
business in Poland.

Create a professional fast food website called "Co Chcesz?" 
for a Polish fast food business specializing in 
Peking Duck and Grilled Chicken.

WEBSITE LANGUAGE: Polish (all text must be in Polish)

PAGES NEEDED (all in Polish):
- Strona główna (Home) with full-screen video background
- Menu page with food photos and prices in zł
- Zamówienie (Order) page - delivery and takeaway
- O nas (About us) page
- Kontakt (Contact) page
- Polityka prywatności (Privacy policy) page

HOME PAGE TEXT (in Polish):
- Header: "Co Chcesz?"
- Tagline: "Najlepsza kaczka i kurczak w mieście!"
- Button: "Zobacz Menu"
- "Godziny otwarcia" (Working hours)
- "Zadzwoń teraz" (Call now)

MENU IN POLISH:
- Kaczka po pekińsku - 89 zł
(Chrupiąca kaczka z sosem hoisin)
- Kurczak z grilla - 49 zł
(Soczysty kurczak z ziołami)
- Sałatka sezonowa - 29 zł
(Świeża sałatka sezonowa)
- Zupa dnia - 19 zł
(Świeża zupa dnia)
- Button text: "Zamów teraz!"

ORDER FORM IN POLISH:
- "Imię i nazwisko" (Name)
- "Numer telefonu" (Phone)
- "Adres dostawy" (Delivery address)
- "Uwagi do zamówienia" (Order notes)
- "Zamów przez WhatsApp"
- "Czas dostawy: 30 minut"

ABOUT US PAGE (Polish):
- "O nas"
- "Nasza historia"
- "Dlaczego jesteśmy najlepsi"
- "Nasza specjalność: Kaczka po pekińsku i Kurczak z grilla"

CONTACT PAGE (Polish):
- "Kontakt"
- "Godziny otwarcia: Poniedziałek-Niedziela 11:00-22:00"
- Phone number clickable
- WhatsApp button

DESIGN:
- Bright red #ff3838 and orange #ff6b00 colors
- Modern fast food style
- Mobile friendly
- Fast loading

REMEMBER: Every single word visible to users must be 
in Polish, not English!
